# Orbit Courier (Орбитальный Курьер) — Unity 2D: минимализм + 10 уровней

Ниже — готовая структура проекта и набор скриптов для прототипа Orbit Courier: запуск дрона, гравитация планет, короткие уровни, быстрый рестарт. Графика — минимализм (кружки и простые формы).

## 1) Что нужно скачать

### Обязательное
1. **Unity Hub** — менеджер проектов и версий Unity.
2. **Unity Editor LTS** (например, 2022 LTS) — стабильная версия редактора.
3. **Android Build Support** (модуль Unity) — для сборки APK.

### Полезное (по желанию)
- **Piskel** или **Aseprite** — если захочется простых иконок.
- **Audacity** — для коротких звуков (старт, удар, победа).

## 2) Структура проекта (уже подготовлена)
В репозитории есть папка `OrbitCourier/Assets`:
- `Scenes` — сцены уровней
- `Scripts` — готовые скрипты
- `Prefabs`, `Sprites`, `Audio`, `SO`

## 3) Список готовых скриптов
Все скрипты лежат в `OrbitCourier/Assets/Scripts`:
- `PlayerController.cs` — запуск «рогаткой», движение, микро‑пульсы.
- `GravitySource.cs` — планеты (притяжение/отталкивание).
- `GravityReceiver.cs` — добавляет силу гравитации к дрону.
- `LevelSession.cs` — таймер, счёт пульсов, рестарт, переходы.
- `GoalStation.cs` — финиш и переход к следующей сцене.
- `RestartOnCollision.cs` — рестарт при столкновении.
- `FragmentCollectible.cs` — сбор фрагментов.

## 4) Как добавить скрипты в Unity (самое простое)
Если скрипты не появились автоматически, их можно создать вручную:
1. В Unity открой окно **Project** → папку `Assets/Scripts`.
2. Правой кнопкой → **Create → C# Script**.
3. Назови файл **точно как в списке** (например, `GravitySource`).
4. Дважды кликни по файлу, вставь код и сохрани.
5. Убедись, что имя класса внутри совпадает с именем файла.
   - Пример: файл `GravitySource.cs` → класс `public class GravitySource`.

### Если Unity ругается на дубликаты (ошибки CS0101/CS0111)
Это значит, что у тебя **две версии одного и того же скрипта**:
- Найди дубликаты в `Assets/Scripts` (например, два `PlayerController.cs`).
- Оставь только один файл, остальные удали или переименуй.
- Проверь, что в одном файле только один класс `PlayerController`.

### Где искать скрипт в Add Component
Скрипты находятся в пространстве имён `OrbitCourier`, поэтому в **Add Component** их можно найти через поиск:
- `OrbitCourier.PlayerController`
- `OrbitCourier.GravitySource`

Если Unity не показывает скрипт в списке компонентов:
- Открой **Console** и исправь ошибки.
- Если ошибок нет, сделай **Assets → Reimport All**.

## 5) Очень подробный старт (как именно создать объекты)
Ниже максимально пошагово, чтобы не было вопросов, где и как создавать объекты и скрипты.

### Шаг 1: Открой проект
1. Открой **Unity Hub** → **Open** → выбери папку `OrbitCourier`.
2. В окне Unity слева снизу открой вкладку **Project**.

### Шаг 2: Создай сцену Level1
1. В окне **Project** открой папку `Assets/Scenes`.
2. Правой кнопкой мыши → **Create → Scene** → назови `Level1`.
3. Дважды кликни по сцене `Level1`, чтобы открыть её.

### Шаг 3: Создай игрока (дрон)
1. В окне **Hierarchy** → правая кнопка → **Create Empty** → назови объект `Player`.
2. В **Inspector** нажми **Add Component**:
   - `Sprite Renderer`
   - `Rigidbody2D` (Body Type: Dynamic)
   - `CircleCollider2D`
3. В `Sprite Renderer` можно оставить стандартный белый квадрат (для минимализма) или выбрать круглый спрайт.
4. Нажми **Add Component** → добавь скрипты:
   - `PlayerController`
   - `GravityReceiver`

### Шаг 4: Создай планеты
1. В **Hierarchy** → **Create Empty** → назови `Planet_1`.
2. Добавь компоненты:
   - `Sprite Renderer`
   - `CircleCollider2D`
   - `GravitySource`
3. Если **GravitySource** не видно в списке:
   - Проверь, что файл `GravitySource.cs` лежит в `Assets/Scripts`.
   - Посмотри внизу окно **Console** — если есть ошибки, Unity не покажет скрипты.
   - Если ошибок нет, попробуй **Assets → Reimport All**.
4. В `GravitySource` настрой:
   - `gravityStrength` (например, 6–10)
   - `gravityRadius` (например, 5–8)
5. Скопируй объект (Ctrl+D), чтобы быстро создать `Planet_2`, `Planet_3`.

### Шаг 5: Создай цель (станцию)
1. **Hierarchy** → **Create Empty** → назови `Goal`.
2. Добавь компоненты:
   - `Sprite Renderer`
   - `CircleCollider2D` → поставить галочку **Is Trigger**
   - `GoalStation` (укажи `nextSceneName`, например `Level2`)

### Шаг 6: Создай менеджер уровня
1. **Hierarchy** → **Create Empty** → назови `LevelSession`.
2. Добавь компонент `LevelSession`.
3. В Inspector укажи ссылки:
   - `player` → перетащи объект `Player` в поле
   - `playerSpawn` (если хочешь) → создай Empty `Spawn` и перетащи

### Шаг 7: Подключи гравитацию к дрону
1. Выбери объект `Player`.
2. В компоненте `GravityReceiver` добавь планеты:
   - Нажми **+** в списке `Sources`
   - Перетащи `Planet_1`, `Planet_2`, `Planet_3`

### Шаг 8: Добавь рестарт при столкновении
1. Выбери планеты (`Planet_1`, `Planet_2`).
2. Нажми **Add Component** → добавь `RestartOnCollision`.

### Шаг 9: Создай фрагменты (по желанию)
1. **Hierarchy** → **Create Empty** → назови `Fragment_1`.
2. Добавь компоненты:
   - `Sprite Renderer`
   - `CircleCollider2D` → **Is Trigger**
   - `FragmentCollectible`
3. Размести 1–3 фрагмента на уровне.

### Шаг 10: Сохрани сцену
`Ctrl+S` → сцена `Level1` сохранится.

## 6) 10 уровней (минимальный контент)
Сделай 10 сцен:
- `Level1` – `Level10`.

Рекомендация по сложности:
- 1–3: 1 планета
- 4–6: 2 планеты
- 7–8: 3 планеты
- 9–10: движущиеся планеты (можно двигать трансформы в Update)

## 7) Минималистичная графика
- Дрон = маленький круг
- Планеты = большие круги
- Финиш = круг с обводкой

Минимализм упрощает разработку и читаемость уровня.

## 8) Сборка APK
1. File → Build Settings → **Android**.
2. Switch Platform.
3. Player Settings → Company Name / Product Name.
4. Build → получаешь APK.
